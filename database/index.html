💡 考试提示
RDS Multi-AZ 与 Read Replica 的区别是必考点（Multi-AZ 用于高可用/故障切换，Read Replica 用于读扩展）。 DynamoDB Global Tables 和 Aurora Global Database 在跨区灾难恢复场景中频繁出现。 ElastiCache 的缓存模式选型（Lazy Loading vs Write-Through）也常考。
