一、Amazon Inspector：持续漏洞管理

Inspector 自动发现并持续评估受支持的 AWS 计算资源、软件包和网络可达性，生成按风险排序的 findings。适合暴露漏洞并辅助修复，不是入侵检测器，也不等同于合规配置审计。

资源面分析内容提示
Amazon EC2软件包漏洞与网络可达性使用 Inspector 管理的扫描机制；评估实例纳管状态、OS/软件包支持
Amazon ECR容器镜像软件漏洞推送时及按配置持续/周期重新扫描；将 findings 接入镜像发布门禁
AWS Lambda函数依赖包漏洞（受支持运行时/部署包）检查功能、部署方式和区域支持
FindingsCVE、严重性、资源与修复建议结合可达性、暴露和业务重要性排序；发现不代表自动修复

Inspector v2 以自动化、多账号资源发现和持续扫描为核心。漏洞库、运行时支持和扫描配置会变化，需按当前文档检查覆盖。

二、覆盖、报告与修复流程

  1. 在目标 Region 启用 Inspector，并通过 Organizations 委派管理员纳管成员账号。
  2. 确认 EC2、ECR、Lambda 覆盖状态；对 ECR 设置扫描频率/仓库范围。
  3. 按严重性、EPSS/可达性、互联网暴露和资产重要性排序 findings。
  4. 应用补丁、更新容器基础镜像/依赖、修复安全组或下线资产，再确认 finding 状态变化。
  5. 通过 EventBridge 或 Security Hub 汇总/路由结果，保留责任人、SLA 和例外审批。
Inspector 报告的是漏洞与暴露风险；AWS Config 用于资源配置合规，GuardDuty 用于威胁活动检测，不能相互替代。

三、Amazon Macie：S3 敏感数据发现

Macie 评估 S3 bucket 的安全态势，并使用托管/自定义数据标识符发现敏感数据类别（如 PII、凭证或财务信息）。自动化发现可持续抽样分析；按需 sensitive data discovery job 可指定 bucket、对象条件和扫描范围。

能力作用边界
Bucket inventory识别 bucket 属性、公开访问/加密等安全风险不修复 bucket policy 或 ACL
Automated discovery持续抽样/发现 S3 敏感数据不是保证扫描每个对象的完整一次性盘点；需要全面扫描时配置 job
Discovery job对选定 bucket/对象运行敏感数据发现成本与样本/处理数据量有关；合理限范围
Finding指出敏感数据类型和所在对象，或 bucket 风险finding 可能包含对象定位等敏感元数据，需保护访问

四、多账号治理与响应

  • Macie/Inspector 均可纳入 Organizations 进行多账号管理，指定 delegated administrator 并覆盖目标 Region。
  • Inspector findings 可发送/汇总到 Security Hub；Macie findings 可通过 EventBridge 集成告警和工作流。
  • 限制 findings、样本结果和导出位置的读取权限；Macie 数据发现结果可能暴露敏感对象路径。
  • 建立漏洞修复 SLA、例外批准和重新扫描闭环；Macie finding 则需数据 owner 评估暴露、保留、加密和访问策略。
  • 费用和扫描覆盖需按 Region、数据量、资源数量与启用计划持续评估。

五、场景题解析（6 题）

1. 需要持续发现 EC2 软件包中的 CVE 和可被网络访问的漏洞。
方向：Inspector EC2 扫描与网络可达性发现；按优先级补丁/收紧网络后重新验证。
2. 每次容器镜像发布前检查已知漏洞。
方向：启用 Inspector ECR scanning，配置仓库/扫描频率，将高危 finding 纳入 CI/CD 发布门禁。
3. 找出 S3 中包含个人身份信息的对象。
方向：Macie automated sensitive data discovery 或针对性 job；检查发现结果、数据分类与访问策略。
4. 要求对指定桶所有对象进行更全面的敏感数据扫描。
方向：定义 Macie discovery job 的 bucket、对象范围与运行计划；自动化抽样发现不等于全量扫描承诺。
5. 多账号集中查看漏洞，但不能用管理账号日常操作。
方向：通过 Organizations 指定 Inspector delegated administrator，纳管成员账号与所有目标 Region。
6. 发现某桶含敏感数据并被公开读取。
方向：Macie 定位敏感数据/风险；通过授权响应流程修正 bucket policy、Block Public Access 或访问权限，并审计影响范围。

八、快速自测

1. 检查 ECR 容器镜像中的软件漏洞，应使用？
正确答案：A。Inspector 支持 ECR 镜像漏洞扫描。
2. 识别 S3 中存储的个人身份信息，应使用？
正确答案：B。Macie 发现并分类 S3 敏感数据。
3. Inspector 报告高危漏洞后，是否会自动替实例安装补丁？
正确答案：B。Inspector 提供发现与建议，修复需由运营流程完成。
