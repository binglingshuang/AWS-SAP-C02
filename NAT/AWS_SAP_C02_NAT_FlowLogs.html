AWS SAP-C02 知识专题

NAT Gateway · VPC Flow Logs · Unsolicited Inbound Traffic

正确答案：D 网络排障与日志分析

一、题目核心与考查目标

题目场景：

  • VPC 已经启用 NAT Gateway Flow Logs。
  • 公网 IP：198.51.100.2。
  • VPC CIDR 前两段：203.0。
  • 日志中出现 Action = ACCEPT。
  • 需要判断公网流量是否属于未经请求的入站连接。
核心问题：
私有 EC2 是否曾主动向 198.51.100.2 发起过连接？ 如果存在匹配的出站连接记录，入站流量可能是该连接的正常返回响应。

本题最终答案

D - Amazon CloudWatch + Private → Public

二、理解 NAT Gateway 的网络工作原理

1. 正常出站访问

Private EC2
203.0.1.10
↓
NAT Gateway
↓
Internet
198.51.100.2

EC2 主动发起连接，允许返回流量

2. 未经请求的入站连接

Internet
198.51.100.2
↓
NAT Gateway
↓
Private EC2

互联网主动发起的新连接，NAT Gateway 不支持转发

3. 必须记住

概念含义
NAT Gateway主要为私有子网提供主动访问互联网的能力
Solicited Traffic内部实例先发起连接，外部返回响应
Unsolicited Traffic外部主动发起未经请求的连接
ACCEPT网络接口层面的流量被允许，不代表 NAT 成功转发
REJECT流量被网络访问控制拒绝

三、四个选项分析

A. CloudTrail + Public → Private

错误：CloudTrail 不是 VPC Flow Logs 的查询工具。

虽然流量方向正确，但日志分析服务选择错误。

B. CloudWatch + Public → Private

错误：查询的是公网到 VPC 的流量。

这可以帮助识别入站流量，但不能直接验证私有实例是否主动发起了对应连接。

C. CloudTrail + Private → Public

错误：查询方向正确，但使用了错误的服务。

D. CloudWatch + Private → Public

正确答案

使用 CloudWatch Logs Insights 查询私有实例是否曾主动访问公网 IP。

四、VPC Flow Logs 字段记忆

字段含义考试记忆

srcPort源端口发送端口
dstPort目标端口服务端口

注意： srcAddr 是源地址，dstAddr 是目标地址。不要根据题目中的 inbound/outbound 单词直接猜选项，要先确认实际 IP 方向。

五、CloudWatch Logs Insights 查询语句

1. 查询 Private → Public（本题 D）

filter (
    dstAddr like '198.51.100.2'
    and srcAddr like '203.0'
)
| stats sum(bytes) as bytesTransferred
    by srcAddr, dstAddr
| limit 10

含义：

  • srcAddr = 203.0：VPC 内部地址。
  • dstAddr = 198.51.100.2：指定公网 IP。
  • sum(bytes)：统计传输字节数。
  • by：按照源地址和目标地址分组。

2. 查询 Public → Private（用于检查入站记录）

filter (
    dstAddr like '203.0'
    and srcAddr like '198.51.100.2'
)
| stats sum(bytes) as bytesTransferred
    by srcAddr, dstAddr
| limit 10

六、如何判断 Solicited / Unsolicited

检查结果可能的判断
存在匹配的 Private → Public 连接发起记录可能是 Solicited
不存在匹配的出站连接发起记录可能是 Unsolicited

进一步验证时应匹配

  • 源 IP 和目标 IP。
  • 源端口和目标端口。
  • TCP / UDP 协议。
  • 时间范围。
  • TCP Flags，尤其是 SYN、SYN-ACK。
重要：不能仅凭同一个公网 IP 的出站记录，就认定入站流量是正常响应。必须确认记录属于同一通信过程。

七、CloudWatch / CloudTrail / Config 区别

服务主要用途关键词

Logs Insights查询日志Filter / Stats / Query
CloudTrail记录 AWS API 操作Who did what

考试口诀：
网络流量找 Flow Logs；
查询日志找 CloudWatch；
谁修改资源找 CloudTrail；
资源配置历史找 Config。

八、SAP-C02 快速答题方法

  1. 识别目标：题目要求判断 unsolicited inbound。
  2. 识别日志：已经启用 VPC Flow Logs。
  3. 识别工具：使用 CloudWatch Logs Insights。
  4. 识别方向：反查 Private → Public 的连接发起记录。
  5. 排除选项：CloudTrail 错误，方向错误也排除。

考场速记口诀

判断入站是否未经请求：
反查内网有没有主动访问外网。

内网 → 公网 = 检查连接发起记录。
公网 → 内网 = 检查入站流量记录。
CloudWatch = 查询 Flow Logs。
