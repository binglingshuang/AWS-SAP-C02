一、实例类型系列

EC2 实例类型由系列前缀、代数、处理器代码和大小组成，如 m6i.xlarge。SAP-C02 考查的是不同系列的适用场景，而非具体型号。

系列前缀特点典型场景
通用型M / TCPU/内存平衡；T 系列支持突发（Burstable）Web 应用、开发测试、小型数据库
计算优化C高 CPU/内存比，最低延迟批量计算、媒体转码、HPC
内存优化R / X / z大内存；X 系列内存最大；z 系列高频内存数据库（SAP HANA）、实时大数据
存储优化I / D / H高 IOPS NVMe SSD（I）或高吞吐磁盘（D/H）NoSQL、数据仓库、分布式文件系统
加速计算P / G / Inf / TrnGPU/FPGA/Inferentia 加速机器学习训练与推理、图形渲染
快速记忆：M = Most general；C = CPU 密集；R = RAM 大；I = IOPS 高；P/G = GPU。T 系列适合波动负载，有 CPU Credit 机制。
考试陷阱：HPC 低延迟首选 C 系列 + Cluster Placement Group，而不是 M 系列。内存型数据库（SAP HANA）选 X 系列，不要选 R。

二、购买选项

购买选项是 SAP-C02 的高频考点，尤其是成本优化场景。

类型折扣幅度承诺期中断风险典型场景
On-Demand无折扣（基准价）无无短期/不可预测负载、开发测试
Reserved（标准）最高 72%1 年 / 3 年无稳定可预测负载（数据库、Web）
Reserved（可转换）最高 54%1 年 / 3 年无需要更换实例系列/OS的场景
Savings Plans最高 66%1 年 / 3 年无承诺固定美元/小时消费，灵活
Spot最高 90%无高（2 min 通知）可容错、无状态批处理
Dedicated Host按需/RI 定价可选 1/3 年无BYOL（按 Socket/Core 许可证）
Dedicated Instance略高于 On-Demand无无合规要求物理隔离，不需 BYOL
Dedicated Host vs Dedicated Instance：Dedicated Host 提供对物理服务器的可见性（Socket/Core 数量），适合 BYOL 软件许可证（Oracle、Windows Server 等）。Dedicated Instance 只保证物理隔离，不提供 Host 级别控制。

Reserved Instance 类型对比

标准 RI（Standard）

折扣最高，但不可更改实例系列、OS 或租户。可在 Marketplace 二手转售。

可转换 RI（Convertible）

折扣略低，但可以交换为同等或更高价值的其他实例类型（不可卖出）。

三、Spot 实例

Spot 实例利用 AWS 闲置容量，折扣高达 90%，但 AWS 可随时回收，提前 2 分钟通知。

核心机制

  • 中断通知：实例被回收前 2 分钟，通过 EC2 实例元数据（IMDS）和 CloudWatch Events 发送中断通知。
  • Spot Block（已弃用）：原本可以锁定 1–6 小时避免中断，AWS 已于 2021 年停止提供新的 Spot Block 购买，考试中如出现此选项通常是干扰项。
  • 中断行为：可配置为停止（Stop）、休眠（Hibernate）或终止（Terminate，默认）。

On-Demand 补充
容量不足时
  • Spot Fleet 允许跨多个实例类型和 AZ 申请 Spot 容量，提高可用性。
  • 分配策略：lowestPrice（最低价格）、diversified（分散到多个池）、capacityOptimized（最大池容量，降低中断率）。
  • 可混合 Spot + On-Demand 满足最低容量保障。

与 Auto Scaling 结合

EC2 Auto Scaling 支持混合实例策略，在同一 ASG 中混合 Spot 和 On-Demand 实例，结合 capacityOptimized 分配策略可以最大化降低中断率。

考试陷阱：Spot 实例不适合：有状态应用、持久数据库、不可中断的批处理任务。适合：无状态 Web 层、CI/CD 测试、大数据 Map-Reduce。

四、置放群组（Placement Groups）

置放群组控制实例的物理位置，影响网络延迟和故障隔离。

类型物理策略优势限制典型场景
Cluster同一机架（单 AZ）最低网络延迟、最高带宽（10 Gbps+）AZ 级别故障影响全部；不支持跨 AZHPC、紧耦合并行计算
Spread不同机架（可跨 AZ）最高故障隔离；每个 AZ 最多 7 个实例每 AZ 7 实例上限关键应用（每 AZ 1 个 Primary）
Partition不同分区（每分区独立机架，可跨 AZ）大规模分布式，每分区最多 100 实例分区间不共享底层硬件Hadoop、Kafka、Cassandra
快速记忆：Cluster = 快（低延迟）；Spread = 安全（隔离）；Partition = 大（分布式）。
注意：Cluster Placement Group 中，如果需要的实例数量超出单个 AZ 的可用容量，启动会失败。建议在非高峰时段一次性启动所有实例。

五、实例存储 vs EBS

特性实例存储（Instance Store）EBS（弹性块存储）
持久性❌ 临时（实例停止/终止即丢失）✅ 持久（独立于实例生命周期）
跨 AZ 迁移❌ 不支持（绑定物理机）✅ 可快照后跨 AZ/Region 恢复
性能极高（NVMe SSD，数百万 IOPS）gp3 最高 16K IOPS；io2 Block Express 最高 256K IOPS
成本包含在实例价格中按容量 + IOPS + 吞吐单独计费
加密特定实例类型支持KMS 加密，创建时启用
典型实例i3、i4i、d2、h1所有实例类型均支持
核心原则：实例存储适合临时缓存、缓冲区、Swap 分区。任何需要持久化的数据（数据库文件、应用日志）必须使用 EBS 或外部存储（S3、EFS）。

六、用户数据（User Data）与实例元数据（IMDS）

User Data

  • 在实例首次启动时以 root 权限执行的 Shell 脚本或 cloud-init 指令。
  • 只在首次启动运行（默认），除非明确配置 cloud-init 在每次启动时执行。
  • 适合：安装软件包、拉取配置、注册服务发现。
  • 通过 http://169.254.169.254/latest/user-data 访问。

实例元数据服务（IMDS）

特性IMDSv1IMDSv2（推荐）
认证方式无需认证，直接 GET 请求需先 PUT 获取 Session Token，再使用 Token 请求
安全性容易受 SSRF 攻击防 SSRF，Token 有 TTL 限制
访问地址169.254.169.254/latest/meta-data/同左，但需 Header: X-aws-ec2-metadata-token
强制启用-可在启动模板/AMI 级别强制禁用 v1
安全最佳实践：强制使用 IMDSv2（HttpTokens: required），可通过 SCP、IAM 策略或 AWS Config 规则在组织级别强制执行。IMDSv1 暴露的凭证是 SSRF 攻击的主要目标。
常用元数据路径：/latest/meta-data/iam/security-credentials/（临时凭证）、/latest/meta-data/instance-id、/latest/meta-data/placement/availability-zone

七、AMI（Amazon Machine Image）

  • 区域级资源：AMI 属于特定 Region，不能直接在其他 Region 使用。
  • 跨 Region 复制：使用 CopyImage 复制 AMI 到目标 Region，同时自动复制底层 EBS 快照。
  • EBS 快照支持：EBS-backed AMI 由一个或多个 EBS 快照组成；Instance Store-backed AMI 由 S3 模板组成。
  • 共享 AMI：可私有共享（按账号 ID）、公开分享或通过 AWS Marketplace 发布。
  • 加密注意：加密的 AMI 复制时会保持加密状态；跨账号共享加密 AMI 需要共享 KMS 密钥。

八、Elastic Network Interface（ENI）高级用法

ENI 是 VPC 中的虚拟网络接口，每个 EC2 实例至少有一个主 ENI（eth0）。

多 IP 地址

  • 一个 ENI 可分配多个私有 IPv4 地址，适合在同一实例上托管多个域名/SSL 证书。
  • 每个私有 IP 可关联独立的弹性 IP（EIP）。

移动 ENI 实现快速故障切换

  • ENI 可在同 AZ 的实例之间移动，迁移后保留私有 IP 和 MAC 地址。
  • 相比 DNS 切换，ENI 迁移几乎零延迟，适合需要毫秒级故障切换的场景。
  • 常用于：网络设备（防火墙、NAT）、许可证绑定 MAC 的软件。
ENI vs EIP：EIP 切换依赖于 IP 重新关联（秒级），ENI 移动同样是秒级但额外保留 MAC 地址（对许可证软件重要）。两者均不需要 DNS TTL 等待。

九、场景题解析

场景 1：公司有一个稳定运行的 Web 应用，预计未来 1 年的流量保持不变，如何最低成本运行？
正确答案：C。稳定可预测的负载 + 明确使用期限 → 标准 Reserved Instance 折扣最高（可达 72%）。全预付比部分预付和无预付折扣更大。
场景 2：数据分析团队需要处理大量可中断的批处理任务，要求最低成本，失败可以重试。
正确答案：B。可容错 + 可中断 + 最低成本 → Spot 实例。使用 Spot Fleet + capacityOptimized 策略可降低中断概率，并通过多实例类型提高容量获取成功率。
场景 3：HPC 集群需要节点间超低延迟通信（MPI 并行计算），如何部署？
正确答案：B。HPC 紧耦合并行计算需要最低延迟 → Cluster Placement Group（同一机架，10 Gbps+ 带宽）+ Enhanced Networking（ENA/SR-IOV）。
场景 4：一个关键数据库服务器需要实现快速故障切换（目标 RTO < 30 秒），不希望依赖 DNS TTL。
正确答案：C。需要保留同一 IP 地址且不依赖 DNS TTL → 移动 ENI（保留私有 IP 和 MAC 地址）。脚本可在故障检测后数秒内完成 ENI 分离和重新挂载到备用实例。

十一、考前速记卡（可勾选）

  • 稳定负载最低成本：标准 Reserved Instance（全预付，最高 72% 折扣）

十二、快速自测

先独立选择，再点击"查看解析"。

1. 一个许可证按 Socket 数量计费的 Oracle 数据库需要迁移到 AWS，应选择哪种购买选项？
正确答案：B。BYOL + 需要 Socket/Core 可见性 → Dedicated Host。Dedicated Instance 只保证物理隔离，不提供 Socket 信息。
2. 团队需要在同一 EC2 实例上运行多个 SSL 证书绑定不同域名，最简单的实现方式是？
正确答案：B。单 ENI 支持多私有 IP，每个私有 IP 关联独立 EIP，可在同一实例上绑定多个 SSL 证书。（注：ALB SNI 是更现代的方案，但此题考查 ENI 多 IP 特性。）
3. 以下哪种情况最适合使用 Partition Placement Group？
正确答案：C。Partition Placement Group 为每个分区提供独立机架，大规模分布式系统（Hadoop、Kafka、HDFS）利用分区信息实现机架感知副本放置。
