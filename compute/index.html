AWS SAP-C02

计算

Compute

SAP-C02 计算模块涵盖从传统 EC2 到无服务器 Lambda、容器化 ECS/EKS 等全谱系，核心考点在于根据场景选择最合适的计算服务及高可用设计。

9 项核心服务

💻
Amazon EC2
可配置虚拟服务器，SAP 考试计算层基础
🔥 高频
核心考点
实例类型选型 购买方式(On-Demand/Reserved/Spot) 置放群组 用户数据 实例存储 vs EBS
📈
EC2 Auto Scaling
根据负载自动伸缩 EC2 实例数量
🔥 高频
核心考点
扩展策略 生命周期钩子 混合实例策略 预测性扩展 暖池
λ
AWS Lambda
无服务器函数计算，事件驱动执行
🔥 高频
核心考点
并发限制 触发器 Lambda@Edge vs CloudFront Functions 容器镜像 冷启动
🐳
Amazon ECS / AWS Fargate
全托管容器编排，Fargate 免运维
🔥 高频
核心考点
Launch Type 对比 Task Definition Service Auto Scaling 网络模式 与 ALB 集成
☸️
Amazon EKS
托管 Kubernetes 服务
⚡ 中频
核心考点
节点类型 Fargate Profile EKS Anywhere IRSA 与 ECS 对比
🌱
AWS Elastic Beanstalk
PaaS 平台，自动处理部署、扩展与监控
⚡ 中频
核心考点
部署策略 环境类型 .ebextensions 与 EC2 的关系
⚙️
AWS Batch
大规模批处理计算作业管理
⚡ 中频
核心考点
Job Queue Compute Environment Spot 集成 与 Lambda 对比
🏭
AWS Outposts / Local Zones / Wavelength
将 AWS 延伸至本地数据中心或边缘位置
⚡ 中频
核心考点
Outposts vs Local Zones vs Wavelength 使用场景 延迟要求
🏃
AWS App Runner
从容器镜像或源代码快速部署 Web 应用
📗 低频
核心考点
与 ECS/Lambda 对比 适用场景
💡 考试提示 ECS(Fargate) vs EKS vs Lambda 的场景选型是高频考点。Fargate 适合无状态容器、Lambda 适合短时事件驱动、EKS 适合已有 Kubernetes 团队。EC2 Spot 实例结合 Auto Scaling 的成本优化方案也是常见考题。
