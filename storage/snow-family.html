AWS Snow Family
离线数据搬运与边缘处理

Snow Family 用于在网络条件有限时把大量数据物理传输到 AWS，或者在边缘站点执行临时计算和筛选。核心决策是：数据量多大、网络是否可用、是否需要边缘处理以及是否需要设备离线迁移。

一、Snow 定位

当网络不够好、数据量太大，或者离线移动数据比增大带宽更有效时，AWS Snow Family 是关键服务。它不是“云存储替代品”，而是“物理搬运 / 边缘计算 / 离线转移”的迁移手段。

关键点说明答题提醒
适用情况公网/专线带宽不足、数据量大、离线迁移更经济。看到“大量数据、网络受限、物理转移”一定要想到 Snow。
核心区别Snowcone 轻量，Snowball 便携，Snowmobile 面向超大规模。题目通常会用“数据量规模 + 离线 / 边缘计算”来区分。
边缘运算Snowball Edge / Snowcone 可在边缘做本地处理或离线筛选。若题目说“边缘 AI/数据筛选/离线计算”，要再联想到 Snow Edge。

二、产品家族

产品主要能力典型使用场景
Snowcone小型便携设备，适合边缘和小规模离线迁移边缘场景、第一次数据搬运、有限现场环境
Snowball Edge更大容量，支持边缘计算和本地处理数据迁移、边缘筛选、离线处理
Snowmobile超大规模物理集装箱式迁移PB 级以上大型迁移
对比口诀：小而轻→ Snowcone；中等可边缘处理→ Snowball Edge；超大规模物理迁移→ Snowmobile。

三、数据量与迁移决策

  • 网络迁移可行且数据量不巨大的场景：优先考虑 DataSync、直接传输或常规 AWS 传输服务，不必使用 Snow。
  • 数据量大到网络不现实：Snow 作为离线物理设备搬运，通常比长时间 WAN 传输更可控。
  • PB 级及以上：Snowmobile 是典型的“超大规模迁移”选型。
  • 边缘处理或离线筛选：Snowball Edge / Snowcone 能在现场做部分计算，减少回传量和网络压力。
最重要的区分：大规模数据迁移靠 Snow；边缘计算和现场处理靠 Snow Edge / Snowcone；真正的云原生存储仍是 S3 / EBS / EFS / FSx。

四、边缘计算、安全与物流

能力重点使用提示
边缘计算在现场处理数据、过滤、转换，减少传回云端的数据量适合连接断开、网络受限或低带宽的场景。
加密和安全使用 AWS KMS 和设备加密，以保护迁移期间数据若题目强调“数据在传输和存储中都要安全”，考虑加密策略。
物流与物理设备Snowball 和 Snowmobile 需要相关交付和运回流程此时要结合规模、时间窗和物理运输成本来选择。

五、场景题解析

场景一：数据中心有 PB 级数据，网络带宽不足

企业需要将大量数据迁移到 AWS，但专线带宽低、平时网络成本高且等待时间不可接受。

正确方向：使用 Snowmobile。

分析思路：题目出现“PB 级超大规模”和“带宽不足”，这是 Snowmobile 的典型场景。

排除：Snowcone / Snowball 更适合中小规模或边缘场景，不适合超大规模搬迁。

场景二：油田 / 远程基地要先筛选后回传数据

现场数据量很大，有网络受限且需要先做过滤、压缩、预处理，再传回云端。

正确方向：Snowball Edge 或 Snowcone。

分析思路：题目强调“边缘处理 + 先筛选后上传”，这是 Snowball Edge / Snowcone 的关键价值。

排除：Snowmobile 主要面向超大规模离线迁移，不是现场处理优先方案。

场景三：需要小型便携设备用于临时离线数据搬运

现场条件有限，数据量不算特别大，但需要一个便携、容易交付和回收的设备。

正确方向：Snowcone。

分析思路：小规模、便携和边缘特点正对应 Snowcone。

排除：Snowball 更像中等规模数据转移设备，而不是最轻量的边缘方案。

六、关键词速查

  • Snowcone = 小型便携设备，适合边缘或小规模离线迁移
  • Snowball Edge = 中等规模且支持边缘计算/处理
  • Snowmobile = 超大规模，适合 PB 级以上离线迁移
  • 离线搬运 = 数据量大、网络不足时使用
  • 边缘筛选 = 先在现场做处理，减少回传流量
  • 数据安全 = 加密、物理设备安全、保管与回收流程

七、考前速记卡

  • Snowcone：小规模/便携/边缘使用
  • Snowball Edge：中等规模 + 边缘计算/筛选
  • Snowmobile：PB 级以上超大规模离线迁移
  • 网络受限：Snow 是解决“大量数据无网络条件”的方案
  • 边缘工作负载：先处理、再上传，减少回传量
  • 安全要求：设备加密、数据保护与物理运输流程不可忽略
  • 不是云存储：Snow 侧重转运与边缘，不是常规云文件系统

八、快速自测

问题 1：数据量超大（PB 级），网络带宽有限且不能长期传输，最合适的是？

正确答案：A。Snowmobile 是针对超大规模离线迁移的产品。

问题 2：需要有边缘计算能力并先筛选数据，再回传云端，最适合哪种设备？

正确答案：B。Snowball Edge 兼具边缘处理能力与数据搬运能力。
