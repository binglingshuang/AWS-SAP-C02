AWS SAP-C02 考试核心考点：Direct Connect (DX) 与 VIF

在 AWS Certified Solutions Architect – Professional (SAP-C02) 考试中，混合云网络架构（Hybrid Cloud Networking）是核心考点之一，而 AWS Direct Connect (DX) 及其 虚拟接口 (Virtual Interfaces, VIFs) 更是高频出现的场景题题材。

一、 核心考点梳理

1. 虚拟接口 (VIF) 的三大类型（必考核心）

考试中经常会给出“企业需要连接什么资源”的场景，要求选择正确的 VIF 类型：

  • Private VIF (私有虚拟接口)
    • 用途：连接到你的 VPC（通过 Virtual Private Gateway - VGW，或者通过 Direct Connect Gateway - DX GW 连接多个 VPC）。
    • 流量特点：私有 IP 流量。
  • Public VIF (公共虚拟接口)
    • 用途：访问 AWS 的公有服务（如 Amazon S3、DynamoDB、EC2 公有 IP 等），使用的是 AWS 的公有 IP 地址空间。
    • 注意：不需要公网互联网，但需要本地网络拥有公有 IP（或经过 NAT 转换）并在 AWS 端配置路由策略。
  • Transit VIF (中转虚拟接口)
    • 用途：连接到 AWS Transit Gateway (TGW)。
    • 场景：当企业拥有多个 VPC 并且架构复杂，或者需要通过一个 DX 连接多个不同区域/不同 VPC 时，必须使用 Transit VIF 配合 DX GW 和 TGW。支持大规模的多对多连接。

2. 架构的高可用与灾备 (Resiliency & Redundancy)

SAP-C02 非常强调“企业级高可用”和“成本与安全平衡”：

  • 单 Direct Connect 的隐患：DX 专线本身是一个单点故障（SPOF）。考试中如果题目要求“最高级别的高可用（High Resiliency）”，绝对不能只买一条专线。
  • 高可用标准方案：
    1. 双专线（跨不同 DX 运营商/不同机房位置）：建立两根或多根 Direct Connect 连接到不同的 AWS Direct Connect 站点。
    2. 备份方案（DX + VPN）：主路走 Direct Connect（高带宽、低延迟），备路走 AWS Site-to-Site VPN（通过互联网，成本低，自带加密）。当 DX 专线断开时，自动通过 BGP 路由切换到 VPN。
  • LAG (Link Aggregation Group)：把多条物理专线捆绑成一条逻辑链路，增加带宽并提供冗余（注意：LAG 中的所有连接必须连接到同一个 DX Endpoint）。

3. 数据安全与加密 (Encryption)

  • 默认状态：Direct Connect 流量默认不加密（明文传输），虽然它走的是运营商专线，但如果企业合规性要求高（如金融、医疗行业），必须加密。
  • 加密方案：
    • 在 Public VIF 上面再建立一条 IPsec VPN（VPN over Direct Connect）。
    • 使用支持 MACsec 的 Direct Connect 专用连接（Dedicated Connections），在物理层直接加密（注意：Hosted Connection/托管连接通常不支持 MACsec，需看具体硬件支持）。

4. 高级特性：SiteLink

  • SiteLink 允许通过 AWS 的全球骨干网，直接在本地数据中心之间（On-premises to On-premises）通过 DX 互联，而无需将流量绕转回 VPC。考试中如果出现“两个海外分公司之间需要低延迟、不通过公网进行数据传输”的场景，多半考的就是 SiteLink。

二、 考试快速答题技巧（“秒杀”关键词）

在做 SAP-C02 题目时，看到特定关键词可以直接锁定答案，节省宝贵时间：

题目中的关键词 / 需求 瞬间联想到的正确答案选项
“Connect to multiple VPCs” 或跨区域 VPC 互联 Direct Connect Gateway (DX GW) + Transit VIF 或 Private VIF
“Connect to AWS Transit Gateway” 必须选 Transit VIF（千万不要选 Private VIF，Private VIF 不支持直接连 TGW）
“Access Amazon S3 / DynamoDB / Public AWS services” 选 Public VIF
“Cost-effective backup” / “Failover if DX fails” 选 AWS Site-to-Site VPN over the internet 作为备用链路
“Maximum resiliency / Enterprise grade” Two connections at different DX locations（两个不同地理位置的 DX 站点专线）
“Increase bandwidth by combining links” 选 LAG (Link Aggregation Group)
“Encrypt traffic over Direct Connect” IPsec VPN over Public VIF 或开启 MACsec（看选项提供哪个）
“Connect two on-premises datacenters via AWS global network” 选 AWS Direct Connect SiteLink

三、 避坑指南（考试常见陷阱）

  • 1. 混淆 Private VIF 和 Transit VIF：
    如果架构里出现了 Transit Gateway (TGW)，VIF 类型必须是 Transit VIF。如果选项里写着用 Private VIF 去连 TGW，直接排除。
  • 2. 混淆加密状态：
    考试中如果问“Direct Connect 是否自带加密？”，答案是不自带。如果题目强调合规性要求加密，必须选择叠加 VPN 或开启 MACsec，不能盲目相信专线本身的物理安全性。
  • 3. 把 Public VIF 当成连 VPC：
    Public VIF 永远是用来连 AWS 公有区域服务（如 S3/DynamoDB）的，绝对不能用来连 VPC 内部的私有 EC2 子网。
